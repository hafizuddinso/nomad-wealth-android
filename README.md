# Nomad Wealth Android

Native Android personal-finance application for users managing money across countries and currencies.

## Features

- Kotlin and Jetpack Compose
- Nomad Wealth landing page
- Supabase email authentication
- Personalized dashboard
- Accounts and transactions
- Loan and installment tracking
- Profile and security information
- GitHub Actions APK build
- Android 8.0+

## Build without Android Studio

Open **Actions**, select **Build Nomad Wealth APK**, run the workflow, and download the APK artifact. See `GITHUB-BUILD-GUIDE.md`.

## Current data status

Supabase handles authentication when configured. Version 1.0 uses local demo financial data; cloud database synchronization is planned.
